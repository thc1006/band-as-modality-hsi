arXiv submission package -- seed-reproducible release (v1.1.0)

Compile: pdflatex main ; pdflatex main
  - NO bibtex: the bibliography is pre-built into main.bbl.
  - \pdfoutput=1 is set on line 1 of main.tex to force pdflatex (the figures are PDF;
    without it arXiv defaults to DVI latex and fails on PDF graphics).

Files in this package:
  main.tex                        (\pdfoutput=1 + the paper source; elsarticle class)
  main.bbl                        (pre-built bibliography -- no bibtex run needed)
  refs.bib                        (bibliography source, for reference only)
  fig2_flagship_reliability.pdf   (Figure 2)
  fig3_domain_gaps.pdf            (Figure 3)
  abstract_plain.txt              (the full abstract, plain text -- paste into the arXiv form)
  abstract_form.txt              (a condensed abstract, if a shorter form field is wanted)

Class: elsarticle (standard on arXiv TeXLive).
Suggested categories: cs.CV (primary), eess.IV, stat.ML.
